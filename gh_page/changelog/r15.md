# Release 15

## New Features

- New actions added:
  - Text-to-speech
  - Run command
  - Axis delta
- Introduced compact version of some UI components.
- Support for pre-empting exclusive macros added, they will interrupt any running macro and resume them once the pre-empting macro completes.
- Switching between light and dark mode applies without restart.
- Added ability to record actions for a macro.

## Bug Fixes

- vJoy conditions no longer broken.
- Conditions with multiple inputs consider all inputs.
- Profiles with modes loading correctly on first load.
- Relative axis working for logical device axes.
- Actions sequence cleared when switching input behavior to avoid incompatible setups.
- Periodic action execution fixes.
- Show correct actions for deeply nested action sequences.
- Correctly reset UI when drag&drop fails.
- Logical device mappings fixed for keyboard inputs.
- Handling of interaction between nested actions improved.
- Profile change detection does not trigger for freshly loaded profiles.
- Handle failure to load user scripts more gracefully.
- Action summaries now readable in dark mode.
- Made split axis action behavior more intuitive.
- Unified and increased number of decimals in input boxes.
- Mouse movement macro action now accepts larger and negative values.
